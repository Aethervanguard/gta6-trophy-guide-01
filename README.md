# Leonida Trophy Guide — GTA VI Trophy Guide & Tracker (PS5)

An offline trophy guide and tracker for Grand Theft Auto VI on PS5. It covers all 55 official trophies, with a step-by-step platinum roadmap that orders the grind so nothing missable slips past.

Every trophy guide cites its sources, so you can check where each tip comes from. Your checklist is saved in the browser, with export and import if you switch devices, and filters plus a spoiler setting let you hide what you do not want to see yet.

Run it locally with `node serve.ts`, or build the submission dossier with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
