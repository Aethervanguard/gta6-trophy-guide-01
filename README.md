A complete, interactive trophy guide for **Grand Theft Auto VI on PS5** — all **55 trophies**, from the first story mission to the Platinum. Built for the [gta6-trophy-guide-01 bounty on make.fun](https://make.fun/bounty/gta6-trophy-guide-01).

## What you get

- **Full checklist** — every one of the 55 trophies with a clear unlock condition, ticked off as you play.
- **Roadmap** — the recommended play order: story first, then side content, then clean-up, so you waste no time backtracking.
- **Missables** — trophies that can be locked out if you pass a story beat or a one-time event, flagged before you reach them.
- **Up next planner** — a planner tab that shows what to chase next based on your progress, with target counters so you can see exactly how far along each grind is.
- **Per-trophy notes** — deeper write-ups on the tricky ones: where to go, what counts, and the fastest reliable method.

## Run it locally

```bash
node serve.ts
```

Then open [http://localhost:8080](http://localhost:8080) in your browser. No build step, no dependencies to install — just the server and the guide.

## About the data

Trophy names, descriptions and unlock conditions are based on official PlayStation trophy data and Rockstar's published information about GTA VI. Where a trophy's exact in-game trigger was still unconfirmed at the time of writing, the guide says so instead of guessing.
